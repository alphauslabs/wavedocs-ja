    WavePRO を使ったスマート予約割引プランの計画・購入・管理

    このガイドの対象者

    このガイドは、Ripple に付属するアルファスのエンドユーザー向けプラットフォーム WavePRO を通じて AWS の利用コストを管理する、クラウド調達担当者・FinOps 実践者・エンジニアリングリードを対象としています。MSP がお客様のアカウントでスマート予約割引サービスを有効化している場合、このガイドでは WavePRO を使ってスマート予約割引プランを安心して計画し、適用率リスクを低減し、保有状況を管理する方法を具体的に説明します。

    このプロセスが重要な理由

    分析なしでリザーブドインスタンス（以下、RI）や Savings Plans （以下、SP）を購入することは、クラウド FinOps において最もよくある、そして最もコストの高い失敗の一つです。コミットしすぎると、使っていないキャパシティに対して料金を払い続けることになります。コミットが足りなければ、30〜40% の割引機会を逃します。

    WavePRO はこの課題に対して、実際の利用履歴に基づいてすべてのスマート予約割引プラン判断を行います。そしてスマート予約割引プランは保証付きであるため、未使用リスクの性質が根本的に変わります—最低利用期間終了後に月次コスト削減額がマイナスになった場合、その差額は返金され、純コスト削減額はゼロに戻ります。※削減額がマイナスというのは購入したRI, またはSPが適用されず無駄になってしまった分の金額をいう。例）適用率が0%のRI, SPの場合はRI, SPの費用全額がそれに該当する。

    WavePRO で知っておくべき 2 つの機能

    WavePRO のスマート予約割引サービス機能は、2 つのセクションで構成されています。

    • スマート予約割引プランのレコメンド — 利用履歴から生成されたスマート予約割引プランのレコメンドを確認し、スマート予約割引プランを購入する機能。
    • スマート予約割引ポートフォリオ — 購入したスマート予約割引プランを管理・追跡する機能。

    注意： 両機能へのアクセスには、MSP が Ripple を通じてお客様のアカウントでスマート予約割引サービスを有効化している必要があります。

    パート1：スマート予約割引プランのレコメンド

    機能概要

    スマート予約割引プランのレコメンド機能は、接続された Cost and Usage Report（CUR）から取得した AWS の利用履歴を分析し、スマート予約割引プランのレコメンドを生成します。

    プランのレコメンドの見方

    最低利用期間とコスト削減プロファイルが異なるプランでレコメンドが提示されます。

    プラン 説明 最短期間
    フレキシブル すべての予約可能サービスに対して 30日間のスマート予約割引プラン。未使用の割引は 30 日後から自動返金されます。 30日

    保証の対象

    • 割引と返金は毎月自動で精算されます—手動管理は不要です。
    • 割引が実現されなかった場合、その差額は自動返金されます。最低利用期間終了後にコストがオンデマンド料金を上回ることはありません。
    • RI/SP は組織内の専用 AWS アカウントで管理されます。WavePRO または AWS コンソールで確認できます。
    • スマート予約利用料は保証に対するコストであり、定額ではなく毎月の実現コスト削減額に対する料率から計算されます。
    • 利用率が低下してコスト削減額が減少した場合、スマート予約利用料も比例して減少します。
    • 月次コスト削減額がゼロになった場合、スマート予約利用料は発生しません。
    • 最低利用期間終了後に月次コスト削減額がマイナスになった場合、その差額が返金され、純コスト削減額はゼロに戻ります。
    • (正規RI/SPの期間の決まり方： お客様が AWS のRI/SP契約期間を選択する必要はありません。システムがコスト削減を最大化する正規RI/SP を自動的に選択します——通常は 3 年契約の正規RI/SP（利用可能な場合）、または 3 年契約が提供されていないサービス（例えば、RDS）の場合は 1 年契約の正規RI/SPになります。)

    プランの選び方

    • フレキシブル（30日）： 利用量が予測しにくいサービス、新しいサービスのトライアル、またはスケールが変化する環境に最適。最短の利用期間で、未使用リスクを最小化できます。

    リスク許容度とコスト削減目標に合ったプランを選択してください。スマート予約割引プランである以上、未使用状態による無駄なコスト発生は限定的です——この保証は、標準的な RI や SP では対応できない低利用率リスクを回避します。

    購入

    レコメンドを確認してプランを選択したら、「プランを適用」をクリックしてスマート予約割引プランを購入します。

    スマート予約割引サービスは、管理アカウントを通じて購入した正規予約割引のみを対象としています。個別に購入した既存の AWS RI または Savings Plans はスマート予約割引プランに移行できません。

    パート2：スマート予約割引ポートフォリオ

    表示内容

    スマート予約割引ポートフォリオ は、購入したスマート予約割引プランの一覧です。アクティブなスマート予約割引プランごとに以下を確認できます。

    • サービスタイプとスマート予約割引プラン
    • 有効期限
    • 利用率 — スマート予約割引プランの現在の利用率。利用率が高いほど、スマート予約割引プランが効果的に活用されていることを意味します。
    • コスト削減効果 — スマート予約割引プランが生成する月次コストと月次コスト削減額。

    活用方法

    • 継続的な管理： 毎月—または大きなワークロード変更の前に—インベントリ を確認して、アクティブなスマート予約割引プランが想定どおりに利用されていることを確認してください。
    • 更新計画： 有効期限を更新カレンダーとして活用してください。適用率のギャップを避けるために、スマート予約割引プランの有効期限の 30〜45 日前に計画プロセスを開始してください。スマート予約割引プランのレコメンド機能に戻り、最新の利用データをもとに新たなレコメンドを生成してください。
    • 利用率レビュー： スマート予約利用料は実現コスト削減額に連動しているため、利用率の低下は利用料の低下を意味します—支払い続ける固定コストではありません。

    エンドツーエンドのワークフローまとめ

    初回セットアップおよび継続的な定常運用のための推奨手順です。

    初回セットアップ

    1. MSP に確認して、Ripple でお客様のアカウントのスマート予約割引サービスが有効化されていることを確認します。
    2. プランナーを開き—最初のレコメンドセットを確認します。
    3. ワークロードに適したプランを選択します（利用履歴が限られている場合や、ワークロードが変動する場合は フレキシブルプラン）。
    4. 最初のスマート予約割引プランを購入します。
    5. スマート予約割引ポートフォリオを確認して、スマート予約割引プランが反映されていることを確認します。購入したスマート予約割引プランが反映されるまで少し時間がかかる場合があります。

    継続的な定常運用（月次）

    1. スマート予約割引ポートフォリオ→ アクティブなスマート予約割引プランを確認し、利用率が正常であることを確認します。
    2. プランナー → 利用パターンの変化に応じた最新のレコメンドを確認します。

    よくある質問

    「利用量が下がった場合はどうなりますか？」 最低利用期間終了後、月次合計コスト削減額がマイナスになった場合、その差額は返金されます—純節約額はゼロに戻ります。

    「利用率が下がってもコスト削減額がプラスの場合は？」 スマート予約利用料は比例して調整されます。利用率の低下はその月の利用料の低下を意味します—ペナルティではありません。

    「既存の AWS RI または Savings Plans をプログラムに移行できますか？」 いいえ。スマート予約割引サービスは、管理アカウントを通じて購入した正規予約割引のみを対象としています。既存の正規予約割引を移行することはできません。

    「プランナー のレコメンドはどの程度正確ですか？」 利用履歴が蓄積されるほど精度が向上します。新しいアカウントの場合、初期のレコメンドは参考値として扱ってください。より信頼性の高いレコメンドを得るために、30〜60 日後に再確認することをおすすめします。

    次のステップ

    最初のプランを実行する準備ができたら？ WavePRO にログインして、スマート予約割引プランのレコメンド に移動してください。

    スマート予約割引プランのオプションが表示されない場合は？ MSP にお問い合わせください—購入オプションが表示されるには、MSP が Ripple でアクセスを有効化する必要があります。
