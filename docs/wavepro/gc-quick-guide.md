# WavePROクイックガイド

*WavePROでスマート予約割引サービスを確認・選択・購入し、購入後に追跡する方法を説明します。*

## はじめる前に

> * ご契約のパートナー様が、お客様のアカウントでスマート予約割引サービスを有効にしていること。  
> * パートナー様から発行されたWavePROのログイン情報があること。請求グループのログインには自動でアクセス権が付与されます。一般ユーザーのログインを使用する場合は、パートナー様がそのユーザーに対してスマート予約割引サービスのレコメンドとスマート予約割引ポートフォリオを有効にする必要があります。

## アクセス方法

パートナー様が用意したアカウントでWavePROにログインし、左側のナビゲーションメニューにある「予約割引」を探します。初めて「予約割引」を開くと、利用規約のウィンドウが表示されます。同意すると先に進めます。規約が更新された場合は「再同意が必要」と表示されるため、新しい規約に同意してください。

✅ 正常な状態：左側のナビゲーションに「予約割引」メニューが表示されています。

⚠️ 注意：「予約割引」メニューが表示されない場合は、お客様のアカウントまたはユーザーで機能がまだ有効になっていない可能性があります。ご契約のパートナー様にお問い合わせください。

## ステップ1：スマート予約割引サービスのレコメンドを開く

| スマート予約割引サービスのレコメンドを開く |
| :---- |
| 「予約割引」\>「スマート予約割引サービスのレコメンド」に移動します。 |
| 「レコメンドプラン」タブを開きます。表示されるプランの多くは、過去のクラウド利用状況から自動で作成されたものです。パートナー様がお客様向けに作成したプランが含まれる場合もあります。 |
| ⚠️ 注意：タブに何も表示されない場合は、分析がまだ実行中の可能性があります。オンボーディング後、完了までに24〜48時間かかることがあります。48時間経っても表示されない場合は、ご契約のパートナー様にお問い合わせください。 |

## ステップ2：レコメンドプランを確認する

一覧の各プランには、主な数値の概要が表示されます。

| 列 | 表示内容 |
| :---- | :---- |
| **プラン** | プラン名と簡単な説明（例：フレキシブルプラン（予約可能なすべてのサービスを対象とした30日間のGRIおよびGSP））。カスタムプランの場合は、パートナー様が付けた名前が表示されます。 |
| **月次割引額** | このプランを適用した場合の、月あたりの推定コスト削減額。 |
| **年間割引額** | 年間の予測コスト削減額。 |
| **適用率の変化** | プラン適用後に適用率がどれだけ変わるかを「適用前 → 適用後」の形式で示します（例：20.0% → 65.0%）。適用率とは、クラウド利用料のうち予約割引が適用される割合です。 |
| **損益分岐点** | プランによるコスト削減の効果が出始め、オンデマンド料金よりも安くなるまでの日数。その下にプランの最低利用期間が表示されます（例：最低利用期間：30日）。 |

| 💡 これらの数値は、お客様のアカウントと利用パターンに固有のものです。 |
| :---- |

## ステップ3：プランを開いて詳細を確認する

プランをクリックすると、詳細画面が開きます。購入前の最終判断にご活用ください。

| セクション | 確認するポイント |
| :---- | :---- |
| **プラン概要** | プランの概要と主なメリット。 |
| **割引** | 月次割引額、プラン適用後の月次コスト、オンデマンドコスト、コスト比較（オンデマンドと比べてどれだけ安くなるか）。 |
| **損益分岐点** | 損益分岐点に達するまでの日数、達成予定日、累積コスト削減額の予測グラフ。 |
| **プラン適用後の適用率** | 現在の適用率、このプランによる追加分、プラン適用後の適用率。 |
| **プラン詳細** | 月次コスト削減額、月次コストの合計（月次コスト＋スマート予約利用料）、前払いコスト、最低利用期間。 |
| **対象サービス** | プランに含まれる各AWSサービスの適用率（高・中・低のバッジ付き）、月次コスト、月次割引額。 |
| **このプランの仕組み** | プランの仕組み、保証の内容、毎月の精算方法、お客様側で不要な作業、予約割引の管理方法。 |

## ステップ4：最適なプランを選ぶ

| プラン | 最低利用期間 | おすすめの用途 | 選ぶタイミング |
| :---- | :---- | :---- | :---- |
| **フレキシブルプラン** | 30日 | 変動が大きい、または新しいワークロード | 利用状況が予測しにくい場合や、スマート予約割引サービスを初めて利用する場合は、まずこちらから。 |
| **カスタムプラン** | プラン作成時にパートナー様が設定 | パートナー様がお客様のアカウント向けにサイズを調整したワークロード | パートナー様が作成したプランが、お客様のニーズに合っている場合はこちら。 |

| 💡 迷ったら：まずはフレキシブルプランから始めましょう。利用履歴が蓄積されるほどレコメンドの精度が上がるため、30〜60日後にスマート予約割引サービスのレコメンドをもう一度確認してください。 |
| :---- |

## ステップ5：プランを適用する

| プランを適用する |
| :---- |
| 「プランを適用する」をクリックします。 |
| 確認画面にプランの詳細が表示されます。内容を確認して「確認する」をクリックします（戻る場合は「キャンセル」をクリック）。 |
| 「確認する」をクリックすると： ✔️ 完了メッセージが表示されます。 ✔️ プランのステータスが「処理中」に変わり、有効になると「実行済み」に変わります。 |
| ⚠️ 注意： 確認画面の内容がプラン詳細画面と一致しない場合は、確定しないでください。先にご契約のパートナー様にお問い合わせください。 |

## ステップ6：購入を確認する

| 購入を確認する |
| :---- |
| 「予約割引」\>「スマート予約割引サービスのレコメンド」\>「申請済み・実行済みプラン」に移動します。 |
| 該当のプランを探します。処理中は「処理中」と表示され、通常は数分以内に「実行済み」に変わります。 |
| 実行済みのプランをクリックすると、ステップ3のプラン詳細画面と同じセクション（「プラン詳細」を含む）に加えて、次の内容を確認できます。 **契約日**：予約割引が実行された日付。 **コスト削減額**：月次コスト削減額、月次予約割引コスト、月次オンデマンドコスト、月次コスト比較。 **対象サービス**：各サービスの適用率（高・中・低のバッジ付き）、月次コスト、月次コスト削減額。 |
| スマート予約割引ポートフォリオに移動し、保有中の予約割引として表示されていることを確認します。反映まで少し時間がかかることがありますが、問題ありません。 |
| ⚠️ 注意：数分経ってもプランが表示されない場合は、ページを更新してください。15〜30分経っても表示されない場合は、ご契約のパートナー様にお問い合わせください。 |

## ステップ7：予約割引を追跡する

スマート予約割引ポートフォリオは、月に1回、またはワークロードを大きく変更する前に確認しましょう。予約割引をクリックすると、次の内容を確認できます。

> * **利用率**：現在の利用率と推移グラフ。利用率が高いほど、予約割引が効果的に使われていることを示します。  
> * **コスト削減効果**：予約割引の月次コストと月次コスト削減額。  
> * **詳細**：有効期限、開始日、ステータス、アカウント名、プロバイダー、支払いオプション、予約割引の種類、数量など。

**更新の計画：**フレキシブルプランは、最初の30日間が過ぎると毎月更新され、その後はどの月でも解約できます。解約方法はご契約のパートナー様にお問い合わせください。期間の長いプランでは、有効期限を更新の目安にしてください。予約割引の有効期限の30〜45日前から、スマート予約割引サービスのレコメンドで最新のレコメンドを確認し、計画を始めましょう。

| 💡 スマート予約利用料は実際のコスト削減額に連動するため、利用率が下がればスマート予約利用料も下がります。固定費を払い続ける必要はありません。 |
| :---- |

## 毎月のチェック項目

> 1. **スマート予約割引ポートフォリオ：利用率に問題がないかを確認します。**  
> 2. **スマート予約割引サービスのレコメンド：利用状況の変化に応じて、レコメンドが更新されていないかを確認します。**

## よくある質問

**「利用量が減った場合はどうなりますか？」**最低利用期間の終了後、月次コスト削減額の合計がマイナスになった場合は、その差額が返金され、正味コスト削減額はゼロに戻ります。なお、最低利用期間中にコスト削減額がマイナスになっても、返金の対象にはなりません。

**「利用率は下がったものの、コスト削減額がまだプラスの場合は？」**スマート予約利用料はコスト削減額に比例して調整されます。利用率が下がると、その月のスマート予約利用料が下がるだけで、ペナルティは発生しません。

**「既存のAWSのRIやSavings Plansを本プログラムに移行できますか？」**いいえ。既存のRIやSavings Plansは移行できません。対象となるのは、管理対象アカウントを通じて購入した予約割引のみです。管理対象アカウントとは、お客様のスマート予約割引サービスを保有する専用のAWSアカウントです。すでにRIやSavings Plansをお持ちの場合や、WavePRO以外で追加購入を予定している場合は、事前にご契約のパートナー様にご相談ください。

**「レコメンドの精度はどのくらいですか？」**利用履歴が蓄積されるほど精度は上がります。新しいアカウントでは、最初のレコメンドを出発点と考え、30〜60日後にもう一度確認してください。

**「プランが有効かどうかはどこで確認できますか？」**「予約割引」\>「スマート予約割引サービスのレコメンド」\>「申請済み・実行済みプラン」に移動してください。「実行済み」と表示されているプランが有効なプランです。

**「スマート予約割引サービスのレコメンドが表示されません」**ご契約のパートナー様にお問い合わせください。お客様のアカウントでスマート予約割引サービスを有効にする必要があります。一般ユーザーのログインを使用している場合は、そのユーザーでも有効にする必要があります。
