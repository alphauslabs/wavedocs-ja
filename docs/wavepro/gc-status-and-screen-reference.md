# ステータス・画面リファレンス

**対象読者：**ステータスの表示や画面の状態が何を意味するのかを知りたい、WavePROのすべてのユーザー。

本ガイドは、地図の凡例のようなものです。画面上の各表示の意味を確認でき、手続きのどの段階にいるのかがいつでもわかります。

## 本ガイドの使い方

本ガイドは、表示される順に画面ごとにまとめています。現在の画面を探し、表示されている項目を確認してください。お急ぎの場合は、最後の「クイック検索」をご覧ください。

## スマート予約割引サービスへのアクセス

**場所：**WavePROの左側のナビゲーションメニュー

| 表示内容 | 意味 | 対応 |
| :---- | :---- | :---- |
| **「予約割引」メニューがない** | お客様のアカウントで、スマート予約割引サービスがまだ有効になっていません。 | ご契約のパートナー様にお問い合わせください。 |
| **「この機能は利用できません」というメッセージ** | お客様のアカウントで、スマート予約割引サービスが有効になっていません。 | ご契約のパートナー様にお問い合わせください。 |
| **「予約割引」メニューは表示されるが、スマート予約割引サービスのレコメンドまたはスマート予約割引ポートフォリオがない** | お客様のユーザーログインに、その機能へのアクセス権がまだありません。一般ユーザーのログインでは、ユーザーごとにアクセスを有効にする必要があります。 | お客様のユーザーに対して、スマート予約割引サービスのレコメンドとスマート予約割引ポートフォリオを有効にするよう、パートナー様に依頼してください。 |

✅ 正常な状態：パートナー様がスマート予約割引サービスを有効にすると、請求グループのログインには自動でアクセス権が付与されます。一般ユーザーのログインでは、パートナー様がユーザーごとにアクセスを有効にする必要があります。

## スマート予約割引サービスのレコメンド：「レコメンドプラン」タブ

**場所：**WavePRO \>「予約割引」\>「スマート予約割引サービスのレコメンド」\>「レコメンドプラン」

このタブには、お客様のアカウント向けに作成されたプランのレコメンドが表示されます。

| 画面の状態 | 意味 |
| :---- | :---- |
| **プランが一覧表示されている** | 利用履歴にもとづいてレコメンドが作成されています。これが通常の状態です。 |
| **カスタムプランが一覧表示されている** | パートナー様がお客様のアカウント向けにプランを作成しました。システムのレコメンドと並んで表示されます。 |
| **プランが表示されない／タブが空** | 分析がまだ実行中であるか（オンボーディング後24〜48時間かかることがあります）、利用データがまだありません。48時間経っても表示されない場合は、ご契約のパートナー様にお問い合わせください。 |

## スマート予約割引サービスのレコメンド：プラン詳細画面

**場所：**WavePRO \>「予約割引」\>「スマート予約割引サービスのレコメンド」\> 任意のプランをクリック

| 項目 | 意味 |
| :---- | :---- |
| **プラン名** | プランの名前。フレキシブルプランなどのプラン名、またはパートナー様が作成したカスタムプランの名前が表示されます。 |
| **月次割引額** | このプランを適用した場合の月あたりの推定割引額。 |
| **コスト比較** | 月次コストがオンデマンド料金と比べてどれだけ安くなるかを、割合で示します。 |
| **スマート予約利用料** | 保証にかかる料金。毎月、実際に得られたコスト削減額に対する割合で計算されます。「プラン詳細」に記載されています。 |
| **損益分岐点：X日** | プランによるコスト削減の効果が出始め、オンデマンド料金よりも安くなるまでの日数。「達成予定日」には、その予定日が表示されます。 |
| **プラン適用後の適用率** | 現在の適用率、このプランによる追加分、プラン適用後の適用率。適用率とは、クラウド利用料のうち予約割引が適用される割合です。 |
| **前払いコスト** | 購入時に支払う金額。フレキシブルプランでは0と表示されます。 |
| **最低利用期間** | 予約割引を維持する最短の期間。フレキシブルプランは30日、カスタムプランはパートナー様が設定した期間です。返金の保証は、この期間の終了後に適用されます。フレキシブルプランは、最初の30日間が過ぎると毎月更新され、その後はどの月でも解約できます。 |

## スマート予約割引サービスのレコメンド：「申請済み・実行済みプラン」タブ

**場所：**WavePRO \>「予約割引」\>「スマート予約割引サービスのレコメンド」\>「申請済み・実行済みプラン」

このタブには、購入したすべてのプランが表示されます。各行には、プラン、月次割引額、最低利用期間、適用率、損益分岐点、ステータスが表示されます。

| ステータス | 意味 | 対応 |
| :---- | :---- | :---- |
| **処理中** | 購入が申請され、処理されています。まだ有効ではありません。購入直後は通常の状態で、多くの場合は数分で完了します。 | 数分後にページを更新してください。変わらない場合は、ご契約のパートナー様にお問い合わせください。 |
| **実行済み** | プランは有効です。予約割引が適用され、コスト削減が反映されています。 | スマート予約割引ポートフォリオで追跡します。 |
| **完了** | プランの期間が終了しました。 | 適用率を維持したい場合は、スマート予約割引サービスのレコメンドで新しいプランを選んでください。プランの終了に心当たりがない場合は、ご契約のパートナー様にお問い合わせください。 |

⚠️ 注意：購入直後にコスト削減額が空欄またはゼロと表示されるのは正常です。最初の請求サイクルが終わると数値が反映されます。

## スマート予約割引ポートフォリオ

**場所：**WavePRO \>「予約割引」\>「スマート予約割引ポートフォリオ」

この画面には、保有しているすべてのスマート予約割引サービスが表示されます。

| 項目 | 意味 |
| :---- | :---- |
| **利用率（%）** | 予約割引のうち、クラウドのワークロードで実際に使われている割合。高いほど良く、予約割引が想定どおりに機能していることを示します。 |
| **コスト削減効果** | 予約割引の月次コストと月次コスト削減額を表示するセクション。 |
| **有効期限** | 予約割引の有効期限。期間の長いプランでは、この日付の30〜45日前から更新の計画を始めましょう。フレキシブルプランは、最初の30日間が過ぎると毎月更新されます。 |
| **月次コスト削減額** | この予約割引で今月実際に得られたコスト削減額（スマート予約利用料を差し引く前の金額）。 |
| **月次予約割引コスト** | 今月の予約割引の総コスト（スマート予約利用料を含む）。 |
| **正味コスト削減額** | 月次コスト削減額からスマート予約利用料を差し引いた金額。 |

この画面のその他の項目：開始日、ステータス、アカウント名、プロバイダー、支払いオプション、予約割引の種類、数量。

| 💡 スマート予約利用料の仕組み：スマート予約利用料は定額ではなく、実際のコスト削減額に対する割合です。コスト削減額が減ればスマート予約利用料も下がり、ゼロのときは0と表示されます。最低利用期間の終了後にコスト削減額がマイナスになった場合は、その差額が返金されます。 |
| :---- |

## ステータスの流れ：開始から終了まで

手続き全体でのステータスの流れは次のとおりです。

**アクセス**  
パートナー様がスマート予約割引サービスを有効化 → 「予約割引」メニューが表示

**プランの購入**  
レコメンドプランを表示 → プランを適用する → 確認する → 処理中 → 実行済み → 完了

**請求**  
プランが実行済み → 最初の請求月が終了 → パートナー様からの次回の請求書にスマート予約利用料を記載

## クイック検索：「この表示はどういう意味？」

| 表示されている内容 | 意味 | 確認する場所 |
| :---- | :---- | :---- |
| 「予約割引」メニューがない、または「この機能は利用できません」というメッセージ | スマート予約割引サービスがまだ有効になっていない | WavePROの左側のナビゲーション |
| 利用規約のウィンドウ | 初回の同意が必要 | 「予約割引」（初回アクセス時） |
| 再同意が必要 | 更新後の規約への同意が必要 | 「予約割引」 |
| レコメンドまたはポートフォリオがない | お客様のユーザーにまだアクセス権がない | WavePROの左側のナビゲーション |
| プランが表示されない | 分析がまだ実行中 | スマート予約割引サービスのレコメンド –「レコメンドプラン」 |
| 処理中 | 購入は申請済みで、まだ有効ではない | スマート予約割引サービスのレコメンド –「申請済み・実行済みプラン」 |
| 実行済み | プランは有効 ✅ | スマート予約割引サービスのレコメンド –「申請済み・実行済みプラン」 |
| 完了 | プランの期間が終了した | スマート予約割引サービスのレコメンド –「申請済み・実行済みプラン」 |
| 購入直後にコスト削減額が空欄 | 正常。最初の請求サイクル後に数値が反映される | 実行済みプランの詳細 – コスト削減額 |
| 利用率（%）が低い | 予約割引が十分に使われておらず、コスト削減額が少なくなる可能性がある | スマート予約割引ポートフォリオ |
