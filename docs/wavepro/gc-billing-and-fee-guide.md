# 請求・料金ガイド

**対象読者：**スマート予約利用料について、その内容、表示されるタイミング、確認場所、返金の仕組みを理解したいWavePROのユーザー。

## スマート予約利用料とは

スマート予約割引サービスには、保証が組み込まれています。最低利用期間の終了後にコスト削減額がマイナスになった場合、その不足分が返金されます（スマート予約割引サービス以外で購入したRIまたはSavings Plansが原因の損失は対象外です）。スマート予約利用料は、この保証にかかる料金です。

**スマート予約利用料について知っておきたいポイント：**

> * 毎月の定額料金ではありません。その月に実際に得られたコスト削減額に対する割合で計算されます（成果報酬型）。  
> * コスト削減額が少なければ、料金も少なくなります。  
> * コスト削減額がゼロになれば、料金もゼロです。  
> * 購入時には請求されません。プランの最初の請求月が終わった後に、初めて表示されます。

## 料金が表示されるタイミング

スマート予約利用料は、購入時ではなく、月次の請求サイクルで計算されます。

| タイミング | 内容 |
| :---- | :---- |
| **購入時** | 料金はまだ発生しません。プランのステータスが「処理中」になり、その後「実行済み」に変わります。 |
| **最初の請求月の終了時** | その月の実際のコスト削減額をもとに、スマート予約利用料が計算されます。 |
| **次の請求サイクル** | スマート予約利用料がWavePROと、パートナー様からの請求書に表示されます。 |

📝 補足：正確なタイミングは、請求の設定によって異なる場合があります。最初の料金がいつ発生するかは、ご契約のパートナー様にご確認ください。

## スマート予約利用料の確認場所

### WavePROで確認する

> 1. WavePROにログインします。  
> 2. 「予約割引」\>「スマート予約割引サービスのレコメンド」\>「申請済み・実行済みプラン」に移動します。  
> 3. 有効なプラン（ステータス：実行済み）をクリックします。  
> 4. プラン詳細画面で、次の項目を確認します。  
   * **コスト削減額：月次コスト削減額（スマート予約利用料を差し引く前の金額）と月次予約割引コスト**（スマート予約利用料を含む総コスト）。  
   * **プラン詳細**：月次コストの合計（月次コストとスマート予約利用料の内訳）。

スマート予約割引ポートフォリオでは、予約割引ごとの月次予約割引コストと正味コスト削減額（月次コスト削減額からスマート予約利用料を差し引いた金額）も確認できます。

✅ 正常な状態：数値が表示されており、月次コストの合計が「月次コスト＋スマート予約利用料」と一致しています。

⚠️ 注意：購入直後に数値が空欄またはゼロと表示されるのは正常です。最初の請求サイクルが終わると数値が反映されます。

### 請求書で確認する

スマート予約利用料は独立した明細項目として請求書に記載されます。自社でクラウドの請求を管理している場合は、請求記録のどこに記載されるかを社内のクラウド請求管理者にご確認ください。

| 項目 | 確認するポイント |
| :---- | :---- |
| **明細名** | スマート予約利用料の請求であることがわかる名称になっているか。 |
| **金額** | その月のコスト削減額にもとづく想定料金と一致しているか。 |
| **請求期間** | プランが有効だった月と一致しているか。 |
| **アカウント** | お客様のアカウントまたは請求グループに請求されているか。 |

✅ 正常な状態：すべての項目が正しく記載され、金額が妥当で、請求期間も正確です。

⚠️ 注意：金額が想定より大幅に高い場合は、コスト削減額の計算に別の基準が使われている可能性があります。ご契約のパートナー様にご確認ください。

## 料金の計算方法

スマート予約利用料は固定額ではありません。毎月、実際に得られたコスト削減額をもとに計算されます。

**簡単な例（金額は円で表示。料率10%の場合。実際の料率は異なる場合があります）：**

| シナリオ | スマート予約利用料を差し引く前のコスト削減額 | スマート予約利用料の料率（例） | 請求される料金 | お客様の最終的な削減額 |
| :---- | :---- | :---- | :---- | :---- |
| RIまたはSPの 適用率が100% | ¥100,000 | 10% | ¥10,000 | ¥90,000 |
| 一部のみ適用 | ¥50,000 | 10% | ¥5,000 | ¥45,000 |
| 利用率が下がり、コスト削減額がゼロになった場合 | ¥0 | 10% | ¥0 | ¥0 |
| コスト削減額がマイナスになった場合（最低利用期間の終了後） | –¥10,000 | — | 料金は発生しません。不足分の¥10,000が**返金**されます。 | ¥0 |

📝 WavePROの表示の見方：スマート予約割引ポートフォリオの正味コスト削減額は、スマート予約利用料を差し引いた後の、お客様の手元に残る金額です。上の表の「お客様の手元に残る金額」の列に相当します。

📝 補足：実際のスマート予約利用料の料率は、ご契約内容で定められています。正確な料率はご契約のパートナー様にご確認ください。料率はプランの最低利用期間によって異なり、30日のフレキシブルプランのように期間が短いプランは、期間が長いプランよりも料率が高くなります。

## 返金の流れ

最低利用期間の終了後に月次コスト削減額がマイナスになった場合（プラン詳細画面に表示）：

> 1. 請求月の終了時に不足分が計算されます。  
> 2. 不足分が返金額として計上され、ご契約のパートナー様からの請求にクレジットとして反映されます。  
> 3. 返金とスマート予約利用料とを合算し、最終的な請求金額を算出します。  
   * 仮に返金額がスマート予約利用料を上回る場合は翌月のスマート予約利用料に充てられます。

| ⚠️ 最低利用期間中：保証はまだ適用されません。得られたコスト削減額にはスマート予約利用料がかかります。また、最低利用期間が終了するまで、コスト削減額がマイナスになっても返金の対象にはなりません。 ⚠️ 保証の対象外：スマート予約割引サービス以外で購入したRIまたはSavings Plansが原因の損失は、返金の対象外です。ほかの方法で予約割引の購入を検討している場合は、事前にご契約のパートナー様にご相談ください。 |
| :---- |

| 💡 お手続きは不要です：返金を申請する必要はありません。返金額は自動で計算され、ご契約のパートナー様からの請求にクレジットとして反映されます。反映される時期や請求書上の記載箇所は、ご契約のパートナー様にご確認ください。 |
| :---- |

## 請求に関するよくある質問

**「プランを購入しましたが、まだ料金が表示されません。正常ですか？」**  
はい、正常です。スマート予約利用料は、プランの最初の請求月が終わった後に初めて表示されます。請求サイクルが1回以上終わっても表示されない場合は、ご契約のパートナー様にお問い合わせください。

**「料金が想定と違います。どうすればよいですか？」**

> 1. スマート予約利用料を差し引く前に、その月にどれだけコスト削減できたかを確認してください。料金はその金額に対する割合です。  
> 2. それでも不明点がある場合はパートナー様に確認してください。  
> 3. それでも差額の理由がわからない場合は、請求期間とプラン名を添えて、ご契約のパートナー様にお問い合わせください。

**「コスト削減額がマイナスになった場合、返金はどこに反映されますか？」**  
ご契約のパートナー様からの請求に、クレジットとして反映されます。請求書の具体的な記載箇所は、ご契約のパートナー様にご確認ください。
